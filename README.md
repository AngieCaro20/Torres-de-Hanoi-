## Torres de Hanoi con Recursividad en Python

Este proyecto es una práctica sobre el problema de las **Torres de Hanoi**, usando **recursividad** en Python. 
La idea es que el usuario escriba cuántos discos quiere mover y el programa le va mostrando los pasos uno por uno hasta completar la solución.


## ¿Qué busca este programa?
- Poner en práctica el concepto de **recursividad**.
- Resolver el problema de mover todos los discos de una torre a otra usando una torre auxiliar.
- Mostrar en pantalla cada movimiento con su número de paso.
- Al final, comprobar cuántos movimientos se hicieron y compararlos con la fórmula `2^N - 1`.



## Reglas básicas del juego
1. Solo se puede mover **un disco a la vez**.
2. No se puede poner un disco grande encima de uno más pequeño. 
3. Todos los discos deben llegar a la torre destino usando la auxiliar.
